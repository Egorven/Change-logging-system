# Название проекта
Система ведения журнала изменений
## Назначение
Приложение предназначено для автоматизации и централизованного учета всех модификаций в программных продуктах. Оно решает задачу создания прозрачной истории версий, упрощает формирование списков изменений (Release Notes) для релизов и обеспечивает удобную навигацию по истории доработок, исправленных ошибок и удаленных функций.
## Целевая аудитория
Разработчики и тимлиды: для фиксации выполненных задач, багфиксов и рефакторинга с привязкой к конкретным коммитам или тикетам.

Менеджеры проектов и продакт-менеджеры: для формирования публичных отчетов о релизах и отслеживания прогресса подготовки новых версий.

Тестировщики (QA): для понимания того, что именно было изменено в конкретной сборке для планирования и проведения регрессионного тестирования.

## Предметная область
Предметная область охватывает процессы управления жизненным циклом разработки программного обеспечения, в частности — конфигурационное управление, контроль версий и релиз-менеджмент. Система работает на стыке технического документирования и треккинга задач
## Основные сущности
- проект
- версия
- изменения
- разработчик
## Основные функции
- Форматирование записи об изменении
- Фильтрация изменений по категории
- Генерация Json-блока для версии
## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
