# Система ведения журнала изменений

Консольное приложение для учета проектов, версий, разработчиков и изменений
в программных продуктах.

## Возможности

- добавление и удаление проектов;
- добавление и сортировка версий;
- добавление записей об изменениях;
- форматирование записей журнала;
- фильтрация изменений по категории;
- сортировка изменений по дате;
- получение статистики по категориям изменений;
- добавление и просмотр разработчиков;
- экспорт данных проекта, его версий и изменений в JSON.

## Структура проекта

- `main.py` - точка запуска и консольное меню;
- `project.py` - работа с проектами;
- `version.py` - работа с версиями;
- `changes.py` - работа с изменениями;
- `developer.py` - работа с разработчиками;
- `storage.py` - сохранение, загрузка и экспорт данных;
- `utils.py` - функции безопасного пользовательского ввода;
- `data/project.json` - данные проектов;
- `data/version.json` - данные версий;
- `data/changes.json` - данные изменений;
- `data/developer.json` - данные разработчиков;
- `tests/` - автоматизированные тесты сущностей;
- `pytest.ini` - настройки запуска тестов.

## Формат данных

Данные приложения хранятся в формате JSON. Каждая сущность представлена
списком объектов с идентификатором `id`.

Запись изменения содержит тип, описание, автора и дату, например:

```json
{
	"id": 1,
	"type": "fixed",
	"description": "Исправлена ошибка при сохранении",
	"author": "Иван Петров",
	"date": "2026-09-10"
}
```

## Требования

- Python 3.10 или новее;
- pytest;
- flake8.

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Запуск тестов
