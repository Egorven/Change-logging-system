# Система ведения журнала изменений (Change-logging-system)

Консольное приложение для учёта проектов, версий, разработчиков и изменений в программных продуктах. Проект реализован с использованием объектно-ориентированного программирования (ООП).

## Возможности

- добавление и удаление проектов;
- добавление и сортировка версий по дате выпуска;
- добавление записей об изменениях с указанием типа, автора и даты;
- форматирование записей журнала в человекочитаемый вид;
- фильтрация изменений по категории (добавлено / исправлено / удалено);
- сортировка изменений по дате;
- получение статистики по категориям изменений;
- добавление и просмотр списка разработчиков;
- экспорт данных проекта, его версий и изменений в JSON.

## Предметная область

Основными объектами предметной области являются:
- **проект** — программный продукт, для которого ведётся журнал изменений;
- **версия** — выпуск проекта с определённой датой;
- **разработчик** — автор изменений;
- **изменение** — запись в журнале, связывающая проект, версию и разработчика.

Разработчик может добавлять записи об изменениях в определённую версию проекта. Каждое изменение имеет тип (добавлено, исправлено, удалено), описание, автора и дату.

## Основные сущности

### Project — проект

Объект `Project` представляет проект, для которого ведётся журнал изменений.

**Основные атрибуты:**
- `id` — уникальный идентификатор проекта;
- `name` — название проекта;
- `description` — описание проекта.

**Основные методы:**
- `__init__()` — конструктор объекта;
- `__str__()` — строковое представление проекта.

### Developer — разработчик

Объект `Developer` представляет автора изменений.

**Основные атрибуты:**
- `id` — уникальный идентификатор разработчика;
- `name` — имя разработчика;
- `role` — роль в проекте.

**Основные методы:**
- `__init__()` — конструктор объекта;
- `__str__()` — строковое представление разработчика;
- `from_data()` — создание объекта из словаря данных (декоратор `@classmethod`).

### Version — версия проекта

Объект `Version` представляет выпуск проекта.

**Основные атрибуты:**
- `id` — уникальный идентификатор версии;
- `name` — название версии (например, «1.0.0»);
- `release_date` — дата выпуска;
- `project` — объект `Project`, к которому относится версия.

**Основные методы:**
- `__init__()` — конструктор объекта;
- `__str__()` — строковое представление версии.

### Change — запись журнала изменений

Объект `Change` представляет запись об изменении в проекте.

**Основные атрибуты:**
- `id` — уникальный идентификатор записи;
- `type` — тип изменения (`added`, `fixed`, `removed`);
- `description` — описание изменения;
- `author` — имя автора;
- `date` — дата изменения;
- `project` — объект `Project`, к которому относится изменение;
- `version` — объект `Version`, к которому относится изменение;
- `developer` — объект `Developer`, автор изменения.

**Основные методы:**
- `__init__()` — конструктор объекта;
- `__str__()` — строковое представление записи;
- `format_entry()` — формирование человекочитаемой строки;
- `is_added()` — проверка, является ли изменение добавлением;
- `is_fixed()` — проверка, является ли изменение исправлением;
- `is_removed()` — проверка, является ли изменение удалением.

## Взаимодействие объектов

Объект `Change` связывает объекты `Project`, `Version` и `Developer`, храня ссылки на них, а не только их идентификаторы. Это позволяет напрямую обращаться к данным связанных объектов:

```python
change.project.name      # название проекта
change.version.name      # название версии
change.developer.name    # имя разработчика
```

Объект `Version` хранит ссылку на объект `Project`, к которому он относится:

```python
version.project.name     # название проекта версии
```

## Основные операции

### Работа с проектами
- добавление проекта;
- удаление проекта (с каскадным удалением связанных версий и изменений);
- просмотр списка проектов.

### Работа с версиями
- добавление версии проекта;
- сортировка версий по дате выпуска;
- просмотр списка версий проекта.

### Работа с изменениями
- добавление записи об изменении;
- фильтрация изменений по типу;
- сортировка изменений по дате;
- получение статистики по категориям изменений;
- просмотр журнала изменений проекта.

### Работа с разработчиками
- добавление разработчика;
- просмотр списка разработчиков.

### Экспорт данных
- экспорт данных проекта, его версий и изменений в JSON.

## Хранение данных

Данные приложения хранятся в JSON-файлах в каталоге `data/`:
- `project.json` — данные о проектах;
- `version.json` — данные о версиях;
- `changes.json` — данные об изменениях;
- `developer.json` — данные о разработчиках.

При запуске приложения данные из JSON преобразуются в объекты классов `Project`, `Version`, `Change` и `Developer`. При сохранении объекты преобразуются обратно в структуры JSON.

Для связи объекта `Change` с объектами `Project`, `Version` и `Developer` в `changes.json` используются их идентификаторы `project_id`, `version_id` и `developer_id`.

## Назначение модулей

### `models/`
Пакет с классами предметной области и функциями работы с коллекциями объектов.

- `project.py` — класс `Project` и функции `add_project()`, `delete_project()`;
- `developer.py` — класс `Developer` и функции `add_developer()`, `find_developer()`;
- `version.py` — класс `Version` и функции `add_version()`, `sort_versions()`;
- `change.py` — класс `Change` и функции `add_change()`, `filter_by_type()`, `sort_changes()`, `get_statistics()`.

### `storage.py`
Отвечает за загрузку и сохранение данных. Выполняет преобразование:
- JSON → объекты Python;
- объекты Python → JSON.

### `utils.py`
Содержит вспомогательные функции безопасного ввода:
- `input_int()` — ввод целого числа;
- `input_date()` — ввод даты;
- `input_text()` — ввод текста.

### `main.py`
Точка входа в приложение. Отвечает за:
- запуск приложения;
- отображение меню;
- получение данных от пользователя;
- организацию пользовательских сценариев.

### `tests/`
Содержит автоматизированные тесты проекта.
